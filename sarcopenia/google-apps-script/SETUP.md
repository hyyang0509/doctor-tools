# 第一場 Google 試算表連結設定

目標試算表：`第一場`，工作表名稱預設為 `工作表1`。

1. 在該試算表點「擴充功能」→「Apps Script」。
2. 清除 `Code.gs` 原有內容，貼入本資料夾的 `Code.gs` 全部內容並儲存。
3. 點右上角「部署」→「新增部署作業」，類型選「網頁應用程式」。
4. 「執行身分」選自己；「誰可以存取」選「任何人」。
5. 完成授權後，複製以 `/exec` 結尾的網頁應用程式網址。
6. 將網址填入 `sarcopenia/config.mjs` 第一場的 `endpointUrl`，再以測試編號送出一筆資料。

注意：此接收端只新增資料，不提供讀取試算表內容的功能。網站為公開 GitHub Pages，部署網址也會出現在公開原始碼中，因此正式使用時只應傳送無法直接識別個人的民眾編號，不可傳送姓名、身分證字號或電話。
