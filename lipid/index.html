資料僅於本頁計算，不上傳、不儲存。

01　病人與目標

選擇最高風險層級。治療前 LDL ≥190 者至少為高風險；不確定時請切換自動分級。

未勾選項目視為沒有；請核對已知病史後分析。

2. ASCVD / 極高與非常高風險條件

勾選已明確成立的診斷或病史。若只是做過診斷性 CAG，請不要勾「血管再通術」。

3. 高風險條件

公告把高風險 CKD 定義為「進入透析治療前」；已透析個案無法單靠這份修訂表判定此項。
目前或治療前 LDL-C ≥190 mg/dL 會自動判定為高風險。

4. 一般心血管風險因子

只有在不符合「高風險以上」時，才用下列項目數量分成中 / 低 / 0 項。
代謝症候群（5 項中 ≥3 項，整體算 1 個風險因子）
目前 0 / 5 項 → 尚不符合代謝症候群
治療前 LDL 與其他血脂（選填）

02　這次用藥

強度依每錠／膠囊的 statin 成分標示；請核對實際每日劑量。
