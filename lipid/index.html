1. 基本資料與血脂

填寫目前血脂與年齡；未勾選的診斷視為沒有，請確認後分析。

2. ASCVD / 極高與非常高風險條件

勾選已明確成立的診斷或病史。若只是做過診斷性 CAG，請不要勾「血管再通術」。

3. 高風險條件

公告把高風險 CKD 定義為「進入透析治療前」；已透析個案無法單靠這份修訂表判定此項。
目前或治療前 LDL-C ≥190 mg/dL 會自動判定為高風險。

4. 一般心血管風險因子

只有在不符合「高風險以上」時，才用下列項目數量分成中 / 低 / 0 項。
代謝症候群（5 項中 ≥3 項，整體算 1 個風險因子）
目前 0 / 5 項 → 尚不符合代謝症候群

5. 目前治療狀態

這部分主要用來判斷何時可加 ezetimibe 或改用 statin + ezetimibe 複方。

6. 要核對的院內藥品

納入 36 個院內碼。短碼、罕藥與其他降脂藥保留原資料，另行核對個別規定。

重要限制

本附件把「表二」內容標成「以下略」，所以若品項落在前六頁排除清單，本工具只能告訴你「改走表二」，不能單靠這份 PDF 判斷表二是否給付。

規則摘要（115/9/1）
  • 極高：LDL ≥55 → 目標 <55（non-HDL <85）
  • 非常高：LDL ≥70 → 目標 <70（non-HDL <100）
  • 高：LDL ≥100 → 目標 <100（non-HDL <130）
  • 中：LDL ≥115 → 目標 <115（non-HDL <145）
  • 低：LDL ≥130 → 目標 <130（non-HDL <160）
  • 0 項風險因子：LDL ≥160 → 目標 <160
