# 血脂工具維護與驗證

規則版本：115/9/1；院內品項來源：使用者於 2026-09-10 提供的兩張截圖（36 個不重複院內碼）。

官方修訂表：https://www.nhi.gov.tw/ch/dl-100842-f34d34af17374f04ae02e87f1ea8ac56-1.pdf

- `formulary.js` 保存院內碼、原圖健保欄、藥名、劑量與成分。截圖短碼和 X 原樣保留，不自行補成健保碼。
- `rules.js` 為不依賴 DOM 的規則；`app.js` 管理畫面。院內品項先依完整健保碼比對表二例外，再套用 2.6.2 / 2.6.3 療程例外。
- 表二、PCSK9、inclisiran、bempedoic acid、lomitapide、TG 藥物及其他未提供完整個別條件者，僅提供品項查詢，不宣稱可給付。
- 表一的一般治療策略提到起始可合併 ezetimibe；實際品項仍逐項核對 2.6.2 / 2.6.3 的診斷、單方療程及不耐受途徑，不能由表一直接跳過個別限制。
- CAD 與 PAD/頸動脈狹窄組合、PAD 的臨床條件分開輸入。MI / ACS / 多支冠脈阻塞視為已有 CAD。≥50% 影像狹窄仍需獨立勾選。
- 目前或治療前 LDL ≥190 均歸入高風險；治療中缺少基線時顯示提示。尚未歸入高風險以上且缺少基線時，不給予加藥符合提示。
- LDL 目標採嚴格小於，恰等於目標仍屬未達標。起始治療門檻與治療目標使用同一 cut-off 的兩側；達標後維持適當治療，不把目標值當停藥門檻。
- 已在 statin 治療者，藥卡主狀態顯示「可維持／可持續既有 statin 治療」，LDL 達標與否獨立顯示為治療狀態，不再以紫色「LDL 未達標」取代給付判定。
- ezetimibe 單方的 statin 不耐受途徑仍需確認符合降血脂藥物給付規定；若目前或治療前 LDL 與風險分級可確認表一資格才顯示綠燈，否則提示核對原始給付資格。
- ezetimibe／複方在 LDL 已達標時，若尚未使用本藥則不符合「治療後仍未達標」新增／換用條件；若已是既有療程，達標本身不是停藥理由。
- 手動 HDL 低值與實測 HDL 不重複計算代謝症候群；已填實測 HDL 低值時自動勾選該項。
- 不儲存、不上傳病人輸入。更新醫療規則前仍需醫師確認來源與解讀。

測試：`node --test lipid/rules.test.js lipid/refactor.test.js`。涵蓋六層風險、性別年齡/HDL/LDL 邊界、PAD 組合、透析、代謝症候群、輸入錯誤、36 品項路徑、6–8 週/3 個月例外、不耐受、既有 statin 達標續用及 gemfibrozil。

## 2026-09-14 藥物評估語意修正

- 主判定改為回答「目前能否新開、續用、加藥／換藥」，LDL 達標與否降為獨立治療狀態。
- statin 治療中不因 LDL 達標而回頭判定不符合起始條件；達標顯示維持治療，未達標顯示可持續並評估強化治療。
- 修正 ezetimibe statin 不耐受路徑：不再只憑「不耐受」直接給綠燈，需同時能確認原始降血脂給付資格。
- 結果頁明確說明表一起始門檻與治療目標為同一 cut-off 的兩側，並註明達標後不代表停藥。
- Service Worker 更新為 v11。

## 2026-09-13 核心重構
